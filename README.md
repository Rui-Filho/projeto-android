# Projeto Android

https://rui-filho.github.io/projeto-android/#

Projeto de estudo desenvolvido durante o curso de HTML5 e CSS3 do [Curso em Vídeo](https://www.cursoemvideo.com/).

O projeto consiste na criação de uma página sobre a história do sistema operacional Android, utilizando HTML5 e CSS3.

## Tecnologias

- HTML5
- CSS3

## Objetivo

Praticar conceitos de estruturação de páginas, estilização, fontes, imagens, links, responsividade e organização de arquivos.

> Projeto desenvolvido para fins de estudo e aprendizado.
